# Triage labels

The skills speak in terms of five triage roles. This maps them to this repo's labels, most of
which the software factory already uses.

| Role (mattpocock/skills) | Label here     | Meaning here                                                                             |
| ------------------------ | -------------- | ---------------------------------------------------------------------------------------- |
| `needs-triage`           | `needs-triage` | The owner needs to evaluate this issue                                                   |
| `needs-info`             | `needs-info`   | Waiting on answers; the implementer also sets it on a ticket it can't build              |
| `ready-for-agent`        | `ready`        | Fully specified. **The factory builds it once its blockers deploy** (`issue-tracker.md`) |
| `ready-for-human`        | `needs-human`  | A human has to do or decide this; the factory also sets it when it stops                 |
| `wontfix`                | `wontfix`      | Will not be actioned                                                                     |

When a skill mentions a role, use the label in the middle column.
